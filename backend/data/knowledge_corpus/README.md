# 已合并的知识库资料

本资料包来自独立采集分支，用户已于2026-11-12授权合并并删除采集工具。
采集程序、网络请求代码及专用依赖已移除；保留清洗正文、来源版本、许可、条款和质量审计记录。

- `owasp/`：246篇OWASP Markdown文档及其来源、固定提交和CC BY-SA 4.0许可。
- `chinese_laws/`：7份中文法律/行政法规资料、393条条款及官方来源。民法典仅节选第1032—1039条。
- `audit/`：合并前清洗检查结果。原报告的“尚未合并”是当时状态，不代表本次合并后的状态。

中文资料可从 [阅读目录](chinese_laws/阅读目录.md) 开始查看。
OWASP资料使用同一知识库的文档导入服务，中文法规进入现有法规文档及条款表，不新增独立检索数据库。
课程绑定、教师审核及学生发布仍使用现有流程，合并资料不伪造这些审批记录。

已采集法规包括网络安全法（2025修正版、2026-01-01生效）、数据安全法、个人信息保护法、网络数据安全管理条例、关键信息基础设施安全保护条例、未成年人网络保护条例及民法典隐私保护条款节选。
部分数据出境配套办法未获取，原待采集事项仅作历史完整性说明；本资料包不再自动更新或联网采集。

## 离线导入和校验

```powershell
python manage.py import_knowledge_corpus --validate-only
python manage.py import_knowledge_corpus --actor <已有管理员ID> --local-index
```

在backend目录、使用项目的正常启动配置执行。命令不爬取资料，验证正文、条款和许可摘要后导入现有知识库；同版本法规复用原记录，重复执行不会重复建立索引。
`--local-index`明确使用现有128维本地确定性索引，不调用远程向量模型，不将其标为语义模型效果。省略该参数时使用项目已配置的向量服务，其失败不会静默切换到本地。
OWASP新文档使用internal可见性，由教师和管理员查看；已存在文档的可见性不被放宽。
