## 3. 本地验证结果

- `python manage.py test learning_map`：36 项通过
- `python manage.py check`：0 issues
- 候选种子：20 能力 / 10 知识点 / 4 任务 / 8 诊断题 / 4 旧标签
- 候选目录发布门禁：`ready=false`，45 项缺失，冻结/发布被阻止
- CASE v1.1 导出：通过 1EdTech/OpenCASE 官方 JSON Schema
- 前端：`npm run build` 通过
- 本地浏览器走通学生地图/诊断/领取与教师审核/学生证据/教师指定任务
- 种子命令幂等，重复执行不覆盖已审核状态

学生接口已做字段隔离：不返回能力/知识点 ID、任务键、证据引用、原因码、规则版本、缺口码与输入摘要；教师接口保留审核字段。

已覆盖的验收场景：新学生待诊断不虚构薄弱项；同输入推荐一致；模型关闭；受助通过后复测；请求未展示不算帮助；帮助记录缺失为未知；环境故障不扣能力；事实幂等/冲突；旧版本保留；发布门禁；里程碑 I 任务不推荐；题池为空；教师指定优先；诊断确定性；越权访问；交付签收不得代填；事件写入失败回滚与重试；CASE/xAPI 格式与隐私。
