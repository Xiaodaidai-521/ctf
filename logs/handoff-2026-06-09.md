### 2. 动态评分管理新增综合总评

需求：学生自评占 30%，管理员评分占 70%，汇成一个总评，并在管理中心“动态评分管理”顶部展示。

实现口径：

- 学生自评：
  - 来源：`StudentProfile.self_assessed_skills`
  - 六方向：`web/crypto/pwn/reverse/forensics/misc`
  - 1-5 星换算为 0-100，再取有效方向平均值
- 管理员评分：
  - 来源：`AdminLearningScore.total_score`
  - 取当前学生最新一条“有效管理员评分”
  - 有效规则沿用现有规则：近 90 天、两次有效评分间隔至少 7 天、最新两次
- 计算总评：
  - `final_score = self_assessment_score * 0.3 + admin_score * 0.7`
  - 任一侧缺失时，不按 0 分硬算，状态为 `incomplete`，前端显示“待补齐数据”

后端改动：

- `backend/learning_analytics/views.py`
  - 新增常量：
    - `SELF_ASSESSMENT_WEIGHT = 0.3`
    - `ADMIN_SCORE_WEIGHT = 0.7`
    - `DIRECTION_KEYS = ('web', 'crypto', 'pwn', 'reverse', 'forensics', 'misc')`
  - 新增：
    - `_normalize_self_assessed_skill`
    - `build_score_summary`
  - `/api/analytics/admin/scores/` 响应新增：
    - `score_summary`

前端改动：

- `frontend/src/admin/views/LearningScores.vue`
  - 在页面顶部新增“综合总评”卡片
  - 展示：
    - 学生自评分
    - 管理员评分
    - 计算后总评
  - 新增 `scoreSummary` 状态和格式化函数
  - `fetchScores()` 拉取并保存 `data.score_summary`

验证：

- `backend\venv\Scripts\python.exe manage.py check` 通过
- `npm run build` 通过
- 管理员评分接口返回 200，并包含 `score_summary`
- 当前数据库没有已有管理员评分记录，因此真实接口样例状态为 `incomplete`；录入有效管理员评分后会自动显示总评
