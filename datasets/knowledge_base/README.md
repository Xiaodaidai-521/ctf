# 知识库候选数据

采集工具和运行说明见 `../../knowledge_acquisition/README.md`。

`raw/` 是被 Git 忽略的可追溯原始数据和缓存；`staged/` 保存 OWASP 资料，`staged_legal/` 保存中文法规。两个候选包均提交在独立采集分支，与 backend/frontend 隔离。

候选包中的 Markdown、JSONL 元数据和质量报告应一起审核。所有资料待人工审核、待绑定课程；没有写入项目知识库或创建向量。

只有用户明确宣布合并后才允许将本分支与业务分支合并。
