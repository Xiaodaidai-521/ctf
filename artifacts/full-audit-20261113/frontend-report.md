## 已自主修复

1. **管理员数据保护接口缺失**：`src/api/index.js` 补齐 7 个方法，对应后端真实的 policies、preview、reveal-requests、reveal-source、stats 路径；保留请求字段。审批入口严格限制 approve/reject/revoke，不能通过审批调用读取原文。新增 URL、字段和审批边界回归。
2. **管理员学习航线假保存**：旧管理页接入现有共享列表/编辑器；保存使用真实 API，保留管理员返回地址。已与后端代理协调真实读写契约及草稿权限。
3. **航线/模块模拟流程**：详情读取该航线本人的服务端进度；区分未加入与读取失败；继续学习使用真实 current_module。模块页改接现有呈现组件，真实调用 start/complete，成功状态以服务器响应为准；去掉模拟实验运行及不存在的 API。
4. **模块笔记缺失**：提供按账号、航线、模块隔离的本机浏览器保存、复制、下载；刷新/离开保护未保存内容。当前为本地笔记，未声称已同步服务器。
5. **正式理论答题错误**：修复题型识别优先级、多选/清空答案、本人已保存答案恢复；按服务器开始时间和考试时长恢复倒计时。读失败/已结束不启动计时器；旧记录响应不能覆盖新记录；提交防重；到期先尝试保存，失败不假交卷；放弃考试读回确认；导航与选项支持键盘；去除原始答案调试日志，结果使用统一记录 URL。
6. **虚构管理统计**：管理员 Dashboard 去掉写死正确率/均分、模拟用户名动态、推算提交次数；接入现有治理工作台数据及模型，失败保持未知，统计入口对应现有页面。
7. **不存在的分类/关注写接口**：分类新建/编辑/删除及文章关注明确禁用，移除假成功。分类列表传递分页参数；没有擅自建立不存在的业务模型。
8. **个人中心数据与跳转**：进度列表使用 learning_path 主键而非进度记录 id；提交列表兼容分页/数组且保留原字段；已解题卡跳到真实 `/challenge/:id`。3 项已有回归及 Chrome 交互通过。
9. **测试可运行性**：增加 `npm test`；修复 3 个测试文件剥离 import 时的 Windows CRLF 兼容问题，保留断言。材料删除及个人中心受影响回归 16/16 通过。

修改局限在前端代码/回归及本目录证据；Docker、后端和部署修改由其他代理负责，未提交 Git。

- 学生成长/首页/旧 Dashboard 8 项布局与数据完整性，另有成长接线 2、旧 Dashboard 导航/下载 1：未知数据不能补成成绩、完整推荐/复习证据下载、角色限定布局等契约仍未落地。
