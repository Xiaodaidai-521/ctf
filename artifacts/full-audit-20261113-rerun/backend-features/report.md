## 仍失败的旧法律合同与需要决定的事项

1. `legal_kb.tests_write_permissions` 要求教师写基础法律库；当前 `IsLegalKbAdmin` 明确仅管理员/staff 可写。教师收到 403，旧测试期望 201；已登记课程材料的教师 re-ingest 旧测试期望 404，但权限先拒绝为 403。本轮没有放宽管理员维护范围来让旧测试通过。需要明确基础库维护权限与课程资料维护的职责，再修订对应测试合同或业务授权。
2. 旧测试设 `EMBEDDING_PROVIDER='local'`；当前服务仅支持空 provider 的明确本地向量或显式 `local_only=True`，以及 qwen/volcano 远程 provider。`local` 字符串返回 `EMBEDDING_PROVIDER_DISABLED`。真实本地回归使用明确 `local_only=True` 已通过。应迁移旧测试为当前注入合同，或正式决定是否支持该配置别名；不能把词法向量结果报告为真实语义模型。
3. 通用 M6 外部/服务器核验仍返回 `server_evidence_not_connected`；M4/M6 向 M7/M8 notices 仍有 `not_connected/target_connected=False`。需要可信核验协议、证据宿主、下游接收与重试对账合同；本轮未伪造这些接入。
4. M7 报告现在必须能在当前环境的 M8 持久库中解析，来自另一环境的 JSON 本身不会创建可信记录。正式评测来源、课程开放范围、独立审批人与发布观察方案仍须确定；生产评测和发布启用不能由合成回归替代。
5. 现有规则推荐与 DKT/AKT/S3Rec 训练模型不是同一实现；正式学习数据、模型质量、供应商凭据/额度与成本评测仍需真实接入。历史空 flag 题目、旧伪造/过期候选报告、乱码综合考试配对等业务数据未自动重写，需要在目标库进行专项数据核对。
