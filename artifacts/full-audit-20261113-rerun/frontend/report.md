## 本轮新增修复

以下是本轮复核后新增的修复，区别于既有 `artifacts/full-audit-20261113/frontend-report.md` 中已完成的改动。工作区原有未提交内容已保留。

1. **候选配置和报告的伪造默认值**：`FeedbackCandidates.vue` 原先不管真实配置都提交 `export_record_limit: 100→120`，登记报告时用当前时间生成运行/报告编号并写死 `pass/completed=true/missing_cases=0`。现在接入既有严格 JSON 解析工具，只允许真实配置/报告文件的原始字段；真实失败、未完成和缺例状态原样送服务端验证。来源校验、摘要一致性和审批绑定仍由后端执行，已与后端代理对齐。
2. **候选导入和写入状态**：替换文件失败会撤销此前的可提交状态；晚返回文件、页面卸载和重复点击不能覆盖当前配置或重复写入；请求使用当时的独立快照。不同候选的报告独立保存。审批范围、观察窗口、回退条件、稳定结论和回退结果改为实际填写，移除原来的固定成功说明；前端不擅自开启服务端闸门。
3. **教师反馈待办与抽查**：读取中、失败、确认空列表和总数未知分开呈现；队列、选项、批次、风险选择、标题读取的错误独立处理。按服务器页码/页大小分页；风险选择遍历全部授权页面，不沿用当前队列筛选，也不把第一页当全集。高风险项可以按可读标题多选，提交原始 ID；批次和动作保留服务端字段。
4. **反馈工作台深链**：队列新增实际存在的 `#feedback-sampling` 原生 disclosure，使既有 `#sampling` 导航能够展开并聚焦抽查区域。嵌入组件发出 ready，避免深链因后续读取改变布局而失位。
5. **反馈详情与事件核对**：主反馈和可选重复反馈按授权列表读取，跨页保留全部符合条件的主反馈；负责人、证据与复测引用接入格式模板导入。动作保留 `expected_version` 和原始关联，增加提交快照、防重与切换记录后的晚响应隔离。可读标题/枚举代替直接显示内部 ID、枚举或数据库异常；完整原始记录继续可下载核对。事件核对标题逐条读取，辅助标题失败不挡住重试动作。反馈页面改用独立、作用域内的共享样式。
6. **验收与抽查页面**：`SkillReviewAdmin.vue` 的 query 页签现在支持首次进入、同路由变化和回退；全体数据读取成功后才更新当前快照，失败不能显示成空待办。常规抽查原先自动提交五项核对全为 true 并填“维持原判”，现在须录入实际核对项、结论与说明；默认全部未勾选，空结论不发请求，同一抽查项防重。新增两项行为回归覆盖未核对项保持 false 与请求快照。
7. **管理员题目管理**：旧页面列表读取引用未定义 `total`，状态筛选未送接口，编辑又要求从只读响应取回/重填答案。管理员页面接入现有教师/管理员共享管理器，复用真实分页、筛选、加载和错误状态。教师与管理员编辑都不读取答案，留空提交省略 `flag` 保留服务端原答案；输入新答案才替换，创建仍要求答案。对应已有测试调整为后端本轮新增的明确契约，并继续断言所有其他原始字段、创建必填和失败表单保持。
8. **管理员资源审核**：旧页直接请求接口、缺完整共享预览/上传接线，失败和数量可能形成误导状态。现在接入现有资源管理器、筛选/分页、完整元数据预览、下载、上传和真实审核对话框；待审核项才能审批/拒绝，拒绝理由原样提交，教师端原权限边界保留。知识资料与材料入口使用现有管理员地址。
9. **公开资源列表**：`Resources.vue` 原先读取失败后直接清空列表并展示“暂无资源”，晚返回响应还能覆盖新类型筛选。增加明确错误/重试状态、未知数量和请求代次；旧请求不能替换新结果或结束新请求的加载状态，卸载后不回写。两条既有行为回归通过，Chrome 另验证 503→错误→重试→服务端确认空列表。
